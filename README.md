# Installer Return Codes for Screen Capture – Screenshot, Record & Manage

This document provides the standard installer exit (return) codes for the **Screen Capture – Screenshot, Record & Manage** application. The installer was built using Inno Setup.

To align with Microsoft Store submission requirements for unique return codes per scenario, the following standard Inno Setup error codes have been mapped to specific failure conditions:

| Return Code | Scenario Mapping | Standard Inno Setup Meaning |
| :--- | :--- | :--- |
| **0** | Installation successful | Success |
| **1** | Installation already in progress | Setup failed to initialize |
| **2** | Installation cancelled by user | User clicked Cancel |
| **3** | Application already exists | Fatal error during preparation |
| **4** | Disk space is full | Fatal error during installation process |
| **5** | Package rejected during installation | Fatal disk write error |
| **6** | Network failure (N/A for offline app) | Fatal file read error |
| **8** | Reboot required | Restart needed |
